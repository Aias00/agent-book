# 附录：术语、检查清单与版本说明

## 学习目标

能够用统一术语阅读 Agent 文档，按发布前清单检查一个 Java Agent，并记录版本和实验边界。

## 原理

模型是生成建议的组件；工具是受约束的动作接口；编排器管理循环和状态；检索提供候选证据；记忆保存经过定义的事实；观测记录系统行为；评测把目标变成可重复任务。

## 术语表

- **工具调用**：模型提出调用，应用验证并执行，应用把结果作为新输入。
- **检索增强**：先从外部语料选择候选，再把证据交给生成步骤。
- **检查点**：可恢复任务在关键状态上的持久化快照。
- **幂等**：同一个请求重复执行不会额外产生不希望的副作用。
- **轨迹**：按时间排序的模型请求、工具调用、状态和结果事件。

## 发布前检查清单

1. Java 测试通过，拒绝、超时、预算和恢复路径有测试。
2. 每个示例输出标注为实际运行输出或示意输出。
3. 每项引用指向来源笔记中的版本和限制。
4. EPUB 有中文元数据、封面、导航和有序阅读顺序。
5. 在线页面能打开章节、代码块和 EPUB 下载链接。

清单不是形式工作：如果不能复现一次测试或定位一次失败，就不要把它写成系统能力。
