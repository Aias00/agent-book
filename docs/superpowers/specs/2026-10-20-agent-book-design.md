## 目标与读者

## 方案选择

推荐：工程学习路线。用一个知识库问答 Agent 串起全书，从确定性模拟工具开始，逐步引入真实模型适配、检索、状态和评测。成本是需要维护示例和自动检查；收益是读者能验证学到的内容。

备选一：概念通识。降低代码门槛，适合零基础，但实践深度较低。

备选二：框架专著。围绕一个框架快速构建应用，但版本依赖较强，读者更难迁移到其他技术栈。

## 拟定目录

前言：如何使用本书、Java 与 HTTP 先修知识、JDK 21 运行环境、学习路线。

1. Agent 的边界：模型、工具、环境、状态；何时使用普通程序或工作流。
2. 大模型基础：上下文、结构化输出、不确定性与模型接口。
3. 最小 Agent 循环：以 Java interface、record 和显式循环表达观察、决策、行动、终止，加入步数与成本预算。
4. 工具设计：JSON Schema、Java 参数类型与业务校验、错误语义与幂等性。
5. 提示与上下文工程：角色、任务、约束、证据和上下文裁剪。
6. 检索增强生成：切分、召回、排序、引用和拒答。
7. 记忆系统：会话状态、长期事实、过期、纠错和删除。
8. 规划与工作流：用枚举和状态转换表达显式状态机，实现检查点、重试与恢复。
9. 多 Agent 协作：任务分解、交接协议、并发冲突与适用条件。
10. 协议与集成：MCP 的职责、工具发现、鉴权与信任边界。
11. 安全与人工审批：提示注入、权限、敏感数据及外部副作用。
12. 评测方法：任务集、基线、工具轨迹、质量与成本。
13. 观测与调试：结构化事件、关联标识、故障定位与回放。
14. 性能与部署：Java HttpClient 超时、ExecutorService 并发、缓存、费用估算和发布策略。
15. 综合实战：构建有引用、可追踪、受预算约束的知识库助手。
16. 从实验到维护：验收、运行手册、升级回归和学习路线。

附录：术语表、练习参考答案、参考资料与版本说明。

各章包括学习目标、原理、具体案例、失败分析、练习和小结。示例输出必须标注实际运行输出或示意输出。参考答案解释思路，避免只列关键词。目标约 4 万至 6 万中文字符，以内容完整性为验收条件，不用篇幅替代质量。

## 示例与资料

核心示例使用 Java 21 与 Maven。业务核心优先使用 JDK，自行解析 JSON 不属于学习目标，模型适配模块可引入固定版本的 Jackson；自动测试使用固定版本的 JUnit。正文讲解用到的 record、sealed interface、HttpClient 等必要语法，不引入 Spring Boot 作为入门前置依赖。框架集成可以作为扩展阅读，不能替代底层机制。

示例具有两条清楚分开的路径：离线模拟模式不调用网络、不需要模型密钥，可运行检索、执行循环及固定评测；可选真实模型模式使用 HttpClient 调用明确标注的模型端点。Maven 首次下载构建依赖需要网络，文档不得把这一步宣称为完全离线。密钥通过环境变量提供；没有密钥时显式跳过真实 API 测试，不把离线模拟的测试结果写成真实模型验证。所有工具执行都经过应用层验证，模型输出不构成授权。

项目按职责分成模型接口与动作类型、Agent 执行器、工具注册与校验、本地知识库检索、状态与检查点、事件追踪、评测入口及模型适配层。测试覆盖业务边界和失败路径。检索教学版可采用可解释的关键词评分，并明确其与向量召回及重排的区别。

围绕同一份小型本地知识库，演示检索、引用、预算、失败恢复与评测；正常路径和失败路径均需可验证。网络示例说明依赖、版本和费用来源，不承诺未实测的效果。

参考资料优先选用论文和官方规范，逐章关联关键结论。已核对七项来源，阅读了四篇论文的摘要、工具调用文档及 MCP 工具章节，并核对 EPUB 规范的文档状态与结构。具体可支持的结论、适用范围和仍需阅读全文的部分见[资料核对与章节证据计划](2026-10-20-source-notes.md)。摘要核对不等于复现论文，也不支持直接引用未阅读的实验细节。
